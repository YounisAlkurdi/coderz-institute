لون عنوان الكورس (h1) - Specificity:
توقعت: يطلع بنفسجي او ازرق غامق حسب ترتيب القواعد.
النتيجه: طلع لون العنوان purple من #course-title.
السبب: الـ id اعلى specificity من الـ class ومن الـ tag، فغلبهم حتى لو h1 مكتوب بالاخير.

تغيير ترتيب قاعدتين - Source Order:
عطلت #course-title وضفت .title { color: orange; } بنهايه الملف:
توقعت: يصير برتقالي لانه اخر اشي مكتوب.
النتيجه: صار برتقالي.
السبب: نفس الـ specificity، والبرتقالي اجى متاخر اكثر بالملف فغلب.

نقلت .title { color: orange; } لقبل .title { color: green; }:
توقعت: يرجع اخضر لانه صار بعد البرتقالي.
النتيجه: رجع اخضر.
السبب: بنفس الـ specificity، القاعده اللي بتيجي بعدين بتغلب اللي قبلها.

لون الفقرتين - Inheritance:
توقعت: الفقره الاولى تاخذ teal والفقره اللي جوا div تضل على لون الكرت (#374151).
النتيجه: الفقره الاولى صارت teal، وفقره Next class: Monday ضلت #374151 موروثه من .course-card.
السبب: .course-card > p بمسك الـ p المباشر جوا .course-card بس، وما بمسك الـ p اللي جوا div.details فضل واخذ لون الكرت.
ليش اخترت > بدل المسافه: المسافه بتمسك اي p جوا الكرت حتى اللي جوا div، اما > فبمسك الابن المباشر لحاله.

الرابط (a) مع hover و focus-visible:
توقعت: يغير لونه لما احط الماوس عليه، ويطلع outline لما اوصله بـ Tab.
النتيجه: لما مررت الماوس صار darkred، ولما شلت الماوس رجع طبيعي، ولما كبست Tab ووصلتله طلعله outline واضح.
السبب: hover بشتغل مع الماوس، وfocus-visible بشتغل لما اوصله بالكيبورد مثل Tab.
